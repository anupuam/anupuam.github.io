3 · The math, step by step

The definition

Pick any complex number c. Start at z₀ = 0 and repeat one rule:

zn+1 = zn2 + c

The Mandelbrot set M is the set of all c for which this sequence stays bounded (never runs off to infinity):

M = { c ∈ ℂ : |zn| stays bounded as n → ∞ }

Every pixel on the image is one value of c: its horizontal position is the real part, its vertical position the imaginary part. Black pixels are in M.

Complex numbers in 30 seconds

A complex number z = x + iy is a point (x, y) in the plane, with i² = −1. Squaring it:

(x + iy)2 = (x2 − y2) + i·(2xy)

Geometrically, squaring squares the distance from the origin and doubles the angle. Then adding c just shifts the point. So each step is “spin-and-stretch, then shift” — that tension between stretching outward and being nudged back is what creates the fractal.

In plain real arithmetic, with z = x + iy and c = a + ib, one iteration is:

x ← x2 − y2 + a     y ← 2xy + b

Why the magic number is 2

We can't iterate forever, so we need a test that proves a point escapes. Here it is: if ever |zn| > 2, the orbit goes to infinity.

Sketch: if |z| > 2 and |z| ≥ |c|, the triangle inequality gives

|z2 + c| ≥ |z|2 − |c| ≥ |z|2 − |z| = |z|·(|z| − 1) > |z|

and since |z| − 1 > 1 is a fixed growth factor, the distance grows at least geometrically — off to infinity. A consequence: the whole set fits inside the disk |c| ≤ 2, touching it only at c = −2.

Points that never pass 2 within our iteration limit are treated as inside. That's why raising Iterations sharpens the edges when you zoom deep: some points only escape after thousands of steps.

Where the colors come from

Black = never escaped. Every other pixel is colored by how fast it escaped — the step number n when |zn| first exceeded the bailout radius. Whole-number n gives visible bands, so this explorer uses the smooth (continuous) escape count:

μ = n + 1 − log2( log2 |zn| )

Because |z| roughly squares each step near escape, log log|z| grows by about 1 per step, so subtracting it fills in the fractional part. μ is then fed into a cosine palette color(t) = a + b·cos(2π(c·t + d)) for each RGB channel. The colors are a visualization choice — the set itself is just the black part.

Anatomy of the shape

  • Main cardioid (the big heart): values of c whose orbit settles to a single fixed point. Its boundary is c = ½eiθ − ¼e2iθ. Its rightmost point is c = ¼ — which is why 0.26 escapes.
  • Period-2 bulb (the disk on the left): the disk |c + 1| ≤ ¼, where orbits settle into a 2-cycle, like c = −1.
  • Smaller bulbs: each one attached to the cardioid has a definite period (3, 4, 5, …). Count the “antennae” spokes on a bulb to read its period.
  • Mini-Mandelbrots: perfect-looking smaller copies appear everywhere along the filaments, at every scale — try the “Mini-Mandelbrot” preset.
  • Proven facts: M is connected (Douady & Hubbard, 1982); its boundary is so wiggly it has Hausdorff dimension 2 (Shishikura, 1998); its area is about 1.506.

The Julia-set connection

For a fixed c, the filled Julia set Kc is all starting points z₀ whose orbit stays bounded. The Mandelbrot set is a “map” of all Julia sets:

c ∈ M  ⟺  Kc is connected  ⟺  the orbit of 0 stays bounded

That's why starting at z₀ = 0 matters: 0 is the critical point of z² + c (where its derivative 2z vanishes), and its fate decides the shape of the whole Julia set. Zooming into M near c even looks like Kc — compare the two pictures in section 2.

The algorithm (what this page actually runs)

for each pixel (px, py):
    a = xMin + px * pixelSize          # real part of c
    b = yMax - py * pixelSize          # imaginary part of c
    x = 0; y = 0; n = 0
    while x*x + y*y <= R*R and n < maxIter:
        x, y = x*x - y*y + a, 2*x*y + b   # z = z² + c
        n += 1
    if n == maxIter:
        color = black                  # assumed inside M
    else:
        mu = n + 1 - log2(log2(sqrt(x*x + y*y)))
        color = palette(mu * density)

Speed-ups used here: points inside the main cardioid or period-2 bulb are detected with a formula and skipped; the image renders progressively so it stays responsive; a large bailout radius (R = 256) makes the smooth coloring cleaner. Zoom depth is limited to about 1013× by JavaScript's 64-bit floating-point numbers.
