    Adding & Updating Publications

    Publications are stored in publications.json in the repository root. Each entry contains the full BibTeX string plus display metadata (title, authors, venue, year, type). To add a new publication, append a new JSON object following the existing format. The page will automatically render the updated list. 

    {
  "id": "unique_cite_key",
  "type": "journal",          // "journal", "conference", "book", "bookchapter", or "textbook"
  "year": 2025,
  "authors": "A. Author, B. Author, and C. Author",
  "title": "Full paper title here",
  "venue": "Name of Journal or Conference",
  "details": "vol. X, pp. YY–ZZ. Publisher, Year",
  "bibtex": "@article{unique_cite_key,\n  author = {...},\n  ...}"
}
